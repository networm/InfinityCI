## 管理页 LDAP 配置 + LDAP 支持补全

### 现状结论（已勘察）
LDAP 核心认证可用（服务账号绑定 + 用户 DN 二次绑定校验、LDAPS、过滤注入防护、首登自动建号角色 User/无本地密码）。缺口：配置仅能改 appsettings 且**需重启才生效**、无管理界面、无连接测试、无组→角色映射、新用户零项目可见性、不支持 StartTLS、搜索无超时、多匹配静默取第一条、零测试、Docker 镜像缺 libldap。

### 一、后端
1. **存储/迁移**：新全局单行表 `LdapSettings`（Id=1）：Enabled、Server、Port、BaseDn、BindDn、EncryptedBindPassword（DataProtection 加密）、UserSearchFilter、DisplayNameAttribute、UseSsl、StartTls、AcceptAnyCertificate、AdminGroupDn、DefaultProject、UpdatedUtc。迁移 v9→v10（CREATE TABLE IF NOT EXISTS）。
2. **`LdapSettingsService`**（新，单例）：`GetAsync()` 返回有效配置——DB 无行时回退 appsettings 绑定值（现网行为不变）；`SaveAsync()`（BindPassword：null=保留已存、空=清除；加密落库；任何 API 不回显明文）。
3. **`LdapAuthenticator` 重构**：不再注入 IOptions（那是启动快照，改配置不生效的根源），改为 `AuthenticateAsync(LdapOptions config, username, password)` 显式传参（virtual 便于测试桩）；新增 StartTls（与 SecureSocketLayer 互斥）；搜索加 TimeLimit 5s；匹配多条目时记警告；组检查：搜索用户时附带读取 memberOf，命中 `AdminGroupDn` 即管理员组。
4. **登录流程**（CiApi MapAuth）：改读 `LdapSettingsService.GetAsync()`；首登建号：角色按组映射（普通=User、命中管理员组=Admin，**绝不自动授 SuperAdmin**），并按 `DefaultProject` 配置自动加入项目可见性；已存在的 LDAP 用户每次登录同步角色（SuperAdmin 永不被自动改动）。
5. **API**（新增 `MapLdap`）：`GET /api/ldap/config`（Admins；不含 BindPassword，返回 hasBindPassword + source=db/appsettings）、`PUT /api/ldap/config`（SuperAdmin；校验 Port/必填）、`POST /api/ldap/test`（SuperAdmin；可用未保存的表单值测试，密码留空用已存值）→ 分步诊断：连接→绑定→BaseDN 搜索→用户过滤器搜索，每步 ok/detail。
6. **Program.cs**：注册 LdapSettingsService；`Configure<LdapOptions>` 保留作为默认值来源。
7. **Dockerfile**：runtime 层 apt 增加 `libldap-2.5-0`（System.DirectoryServices.Protocols 在 Linux 需要本机 libldap）。

### 二、前端
8. **admin.tsx** 新增 `LdapSection`（沿现有区块模式）：Admin 可见；字段全覆盖（密码显示"已配置，留空保持不变"）；[保存]（SuperAdmin）、[测试连接]（SuperAdmin）按钮展示分步诊断结果（每步 ✓/✗ 与错误详情）。
9. `api.ts`/`types.ts`：LdapConfig 类型 + get/save/test 三个 API；i18n zh/en 成对新增 admin.ldap* 文案。
10. 登录页横幅自动跟随有效配置（`/api/auth/config` 改读有效配置，接口形状不变）。

### 三、测试
- LdapSettingsService：无行回退 appsettings、保存/读取、密码加密且不回显。
- 登录流程（Authenticate 设为 virtual 供测试桩）：LDAP 首登建号（角色 User）、命中管理员组授 Admin、禁用 LDAP 时 401、本地账号优先。
- API 权限：GET Admins、PUT/test 需 SuperAdmin。

### 四、验证与明确不做
- `dotnet build/test` + `npm typecheck/build`；重启后浏览器验证：管理页区块、保存后即时生效（无需重启）、连接测试对无效服务器给出分步诊断；真实 LDAP 服务器不可用，成功路径靠诊断输出与单测覆盖，失败路径实测。
- 明确不做：嵌套组、多组多角色、证书固定、账号禁用联动、连接池。
