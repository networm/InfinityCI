# v5：任务禁用/启用 + Webhook 触发 + 企业微信通知

## 1. 任务禁用/启用（管理员及以上）

- **存储**：新表 `WorkflowState`（WorkflowName 主键、Enabled 默认 true、WebhookToken 唯一可空、NotifyWebhookUrl 可空、变更时间）。禁用/启用是**运行态操作**，存 DB 而不写进 YAML——避免污染配置 Git 仓库。
- **API**：`POST /api/jobs/{name}/enabled { enabled }`（Admins 策略）→ upsert；`GET /api/jobs`、`/api/dashboard`、任务详情 raw 页均返回 enabled。
- **拦截**：`RunQueueService.TriggerAsync` 检查状态，禁用时抛「任务已禁用」→ API 返回 409；Webhook 触发同样被拦截。
- **前端**：Dashboard 行与任务页表格显示「已禁用」徽章、Run 按钮置灰；任务详情页头部对管理员显示 启用/禁用 切换按钮。

## 2. Webhook 触发任务

- `WorkflowState.WebhookToken`：管理员在任务详情页一键生成（24 字节 hex），可撤销重置。
- **触发端点**：`POST /api/webhooks/{token}`（匿名，token 即鉴权）：
  - body 可选 `{ "params": { k: v } }`（或 query 参数同名传入），走与手动触发完全相同的参数合并/required 校验
  - `triggeredBy = "webhook"`；任务禁用 → 409；token 不存在 → 404
- **API**：`POST /api/jobs/{name}/webhook-token`（生成并返回完整调用 URL + token）、`DELETE /api/jobs/{name}/webhook-token`（撤销）。
- **前端**（任务详情页，管理员）：Webhook 区块——生成/复制 curl 示例、撤销按钮。

## 3. 企业微信机器人通知

- `WorkflowState.NotifyWebhookUrl`：每任务可配企业微信群机器人 webhook 地址（管理员在任务详情页设置/清除）。
- **WeComNotifier**（单例，HttpClient + IHttpClientFactory）：订阅 `RunEvents.RunUpdated`，Run 进入终态且配置了 URL 时 POST 企业微信机器人消息：
  ```json
  {"msgtype":"markdown","markdown":{"content":"**Infinity CI**\n> 任务：<font color=\"info\">demo</font> #12\n> 状态：<font color=\"warning\">失败</font>\n> 触发人：管理员\n> 耗时：8分14秒"}}
  ```
  （成功 info 绿、失败 warning 红；无 URL 或非终态跳过；发送失败仅记日志不影响系统）
- **API**：`PUT /api/jobs/{name}/notify-webhook { url|null }`（Admins）。
- 单测：消息体格式化函数 + 终态触发通知的流程（stub HttpMessageHandler）。

## 4. 前端（任务详情页为管理入口）

任务详情页 Header 下方新增「自动化」管理卡片（管理员可见）：
- 启用/禁用 切换
- Webhook 触发：生成/撤销令牌 + 可复制的 curl 调用示例
- 企业微信通知：机器人 URL 输入保存 / 清除

Dashboard 行、任务页表格显示「已禁用」徽章并置灰 Run。
